## The four to know

### Linden (KLDJ), Linden, NJ

| | |
|---|---|
| Tower | None. CTAF 123.0 |
| Runway | 9/27, 4,140 ft |
| Airspace | {{< todo "Class B floor overhead (check the NY TAC)" >}} |
| Getting there | NJ Transit to Linden from Penn Station, then about 2 miles by taxi. About 23 miles by car from Midtown, or 14 from St. George, Staten Island, via the Goethals Bridge |
| Who flies here | [Richmond Pilots](/) (club), [LuvsFlying](https://www.luvsflying.com) (flight school) |
| Good to know | Touch-and-gos for based aircraft only; others need prior permission. Landing fee for transient aircraft |

### Morristown (KMMU), Morristown, NJ

| | |
|---|---|
| Tower | Yes, 6:45 am–10:30 pm |
| Runways | 5/23, 5,998 ft; 13/31, 3,997 ft |
| Airspace | Class D while the tower is open |
| Getting there | NJ Transit Morristown Line to Morristown, then about 4 miles by taxi. About 32 miles by car from Midtown |
| Who flies here | [Certified Flyers](https://www.certifiedflyers.com), [ATP](https://atpflightschool.com/local/mmu) |
| Good to know | Busy with business jets. Landing fee and a noise program |

### Essex County / Caldwell (KCDW), Fairfield, NJ

| | |
|---|---|
| Tower | Yes, 7 am–11 pm |
| Runways | 4/22, 4,552 ft; 10/28, 3,719 ft |
| Airspace | Class D while the tower is open |
| Getting there | NJ Transit Montclair–Boonton Line to Little Falls (rush hours only), then about 5 miles by taxi. About 22 miles by car from Midtown |
| Who flies here | [Paramus Flying Club](https://www.flyingclub.org) (club), [Costanzo Air](https://www.costanzoair.com), Essex Air, [ATP](https://atpflightschool.com/local/cwd) |
| Good to know | Touch-and-gos for based aircraft only. No local pattern work 11 pm–7 am |

### Republic (KFRG), Farmingdale, NY

| | |
|---|---|
| Tower | Yes, 7 am–11 pm |
| Runways | 14/32, 6,833 ft; 1/19, 5,517 ft |
| Airspace | Class D while the tower is open, under the New York Class B |
| Getting there | LIRR Main Line to Farmingdale, then about 3 miles by taxi. About 37 miles by car from Midtown |
| Who flies here | [Long Island Aviators](https://longislandaviators.com), [Academy of Aviation](https://www.academyofaviation.com/farmingdale/), [Nassau Flyers](https://www.nassauflyers.com) (Cirrus), [Airborne Elite](https://flyforreal.com) (light sport), and more |
| Good to know | Landing fee for all civil aircraft. Voluntary noise abatement |
